💻 Getting Started

No complicated setup is required to start learning.

Clone this repository:
bash
git clone https://github.com/YOUR-USERNAME/javascript-learning-hub.git
Open the project folder:
bash
cd javascript-learning-hub
Open any .js file and read the examples.
Run JavaScript using your browser's developer console or Node.js.
📝 Your First JavaScript Program
javascript
// Print a message
console.log("Hello, JavaScript!");

// Variables
const name = "Developer";
let age = 20;

// Display information
console.log(`Hello, ${name}!`);
console.log(`Your age is ${age}.`);

// Function
function add(a, b) {
    return a + b;
}

console.log(add(5, 3)); // 8


Expected output:

text
Hello, JavaScript!
Hello, Developer!
Your age is 20.
8
